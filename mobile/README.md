# 司凤星球 Android

安装 `sifeng_planet_android.apk`（Android 8.0 及以上）。首次进入按三步设置搜索词、播放方式、悬浮胶囊；也可跳过。开启悬浮胶囊时，系统会打开“显示在其他应用上层”授权页；授权后播放歌曲，白色横向胶囊才会出现，点击可返回播放器。不开启时不会请求此权限。

手机端采用原生 Android `MediaPlayer` 从视频地址流式播放，无需等文件完整下载；页面随手机宽度伸缩，底部固定导航可进入发现、收藏、记录、播放和设置。收藏与记录存储在本机应用数据中。

播放接口先保存哔哩哔哩会话 Cookie；如按 BV 号请求失败，会尝试用搜索结果里的 AV 号获取分页与播放地址，并尝试 HTML5 MP4 地址。接口缺少 `data` 时会显示实际错误码。搜索轮流按播放量和随机推荐：第一次高播放量、第二次随机、第三次高播放量，以此类推；“换一批”也参与轮换。

播放所需 `cid` 使用 64 位整数读取；新视频的 `cid` 可能超过 32 位范围，若截断会导致播放地址接口返回 `-400`。

源码位于 `mobile/`。构建：安装 Android SDK 34，然后在 `mobile` 目录运行 `gradle :app:assembleDebug`。
