# 司凤星球

白色简洁桌面听歌程序。首次进入先以放慢的曲线动画呈现“司凤星球”，再逐步配置搜索词、播完模式、关闭行为、切歌快捷键和悬浮胶囊；每一步都可以返回或跳过。所有主页面切换有轻柔渐显动画，按钮只带很淡的小阴影。

## Windows 桌面版

双击无控制台窗口的 `SiFengPlanet.exe` 即可运行，无需安装 Python。源码方式仍可双击 `start_sifeng.cmd`，或先执行 `pip install -r requirements.txt` 再运行 `python sifeng_planet.pyw`。需要联网。

本次重新打包移除了与 PySide6 不兼容的 ICU DLL，修复启动时 `QtCore` 的 DLL 加载错误。

首页搜索框会直接向哔哩哔哩发起三次搜索，分别把输入词与「司凤」「司凤版」「隆德齐」组合，结果仍按标题条件筛选，不再只过滤已加载卡片。「随机刷新」会更换搜索结果页并打乱顺序。首页横向推荐卡右上角的关闭按钮会把卡片滑向顶部「正在播放」，并短暂提示入口；收起卡片不会停止播放。

点开视频后取得 MP4 地址，通过本地流代理边传输边播放，不等待完整下载，也不使用网页 HTML5 播放器。已接收片段写入缓存；完整缓存的歌曲下次可直接播放。

顶部自绘 SVG 按钮为最小化、最大化／还原、关闭。关闭按钮按设置收进托盘或完全退出；托盘菜单可以重新打开或退出。播放器支持暂停、上一首、下一首和拖动进度条。视频卡片右上角可加入“本地收藏”；“司凤记录”保存实际播放过的视频。默认全局切歌快捷键为 `Ctrl+Alt+N`。

完整视频缓存位于 `%LOCALAPPDATA%\SiFengPlanet\Cache`，旧完整缓存自动清理到约 150 MB 以下。收藏、历史和偏好位于 `%APPDATA%\SiFengPlanet`。

## Android 手机版

另附 `sifeng_planet_android.apk`，Android 8.0 及以上安装。手机端支持输入词组合实时搜索；搜索结果按“高播放量、随机、高播放量、随机”轮换，“换一批”也参与轮换。采用原生播放与窄屏布局，底部固定导航，支持收藏、记录、顺序／单曲循环／随机。首次开启悬浮胶囊时会跳转系统悬浮窗授权页；授权后，播放时显示缓慢旋转封面的横向胶囊。手机端的收藏、记录与桌面版分别保存在各自设备上。

播放时先获取会话 Cookie；按 BV 号请求遇到 `-400` 等失败后，改试搜索结果中的 AV 号和 HTML5 MP4 地址；如果站点仍拒绝请求，界面会显示实际接口错误码和说明。

新版 APK 进一步修复 `cid` 以 32 位整数读取导致的溢出：以“雨爱”热门视频测试，错误的截断值返回 `-400`，保留完整 64 位数值后返回 `0` 和 MP4 地址。
